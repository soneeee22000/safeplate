# Event-day notes

These are the working notes from the Gemma 4 Hackathon Paris (42 Paris, Track 2,
Autonomous Agents), kept as they were written on the day, apart from small edits. They record what was planned
and said at the time, including numbers, links and plans that later changed.

Where anything here differs from the [main README](../../README.md), the README
describes the code as it runs now and takes precedence. In particular:

- **"5B model".** The notes call Gemma 4 E2B a 5B model. E2B has about 2B effective
  parameters; the README uses that figure.
- **The competition submission.** The write-up draft, its checklist and its links were for the
  event's submission process, which is closed. They are not how to reach the project now.
- **Team roles and budget.** The notes and the design docs assign build roles across the team
  and mention the event's credit budget. They record the plan for the day, not who wrote the
  code in this repo; the commit history does that.
